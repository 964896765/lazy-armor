# 懒人装甲产品定义

懒人装甲帮助用户高效完成目标计划。聊天、应用、数据、设备、工具和外部服务都是计划可调用的资源，不形成彼此割裂的产品核心。

## 用户主线

```text
目标 → 计划 → 资源解析 → 运行 → 验证 → 结果
```

计划是唯一的用户工作单元。计划模板是常见目标的可复用起点；用户也可以在问一问中直接描述目标。系统只在需要判断、授权、补充信息或承担风险时请求用户处理。

## 信息架构

- 首页：今日重点、正在运行、待处理和推荐。
- 计划：发现计划模板、创建计划、管理状态和查看结果。
- 问一问：回答问题、理解目标、生成或修改计划草稿。
- 资源：查看应用、数据、设备、能力、授权和健康状态。
- 服务：发现能补齐计划资源缺口的现实供给。

消息和待处理位于全局注意力入口。个人资料、安全、隐私和设置由首页头像进入。

## 统一术语

- Goal：用户希望达成的结果。
- Plan：实现目标的唯一用户工作单元。
- Plan Template：可复用的计划起点。
- Resource：计划可以读取、调用、使用或购买的对象。
- Capability：资源能够提供的信息或动作。
- Run：计划的一次推进或执行实例。
- Result：经过验证后交付给用户的结果。
- Attention：需要用户确认、补信息、修复连接或判断的事项。

旧 Scenario、Strategy、Task 仅可存在于历史数据、迁移和兼容适配中，不得作为新产品语义。
